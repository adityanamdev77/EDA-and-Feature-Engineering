# 📊 EDA and Feature Engineering

**Exploratory Data Analysis (EDA) and Feature Engineering using Python**

## 📌 About the Project

This repository contains practical implementations of Exploratory Data Analysis (EDA) and Feature Engineering techniques using Python. It focuses on understanding datasets, cleaning data, discovering patterns, visualizing insights, and preparing features for Machine Learning models.

## 🎯 Objectives

- Understand datasets using statistical analysis.
- Identify and handle missing and duplicate values.
- Detect outliers and analyze data distributions.
- Explore relationships and correlations between features.
- Create and transform meaningful features.
- Apply feature scaling and categorical encoding.
- Prepare clean, high-quality data for Machine Learning.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
